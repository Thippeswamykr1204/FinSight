# Visual QA

Visual QA checks that the web experience remains coherent across the routes,
themes, and screen sizes supported by the product.

- Review the relevant route in light and dark themes when a visual change is
  made.
- Check mobile and desktop widths when a change affects responsive behavior.
- Keep the route, browser, fonts, theme, viewport, and data state consistent when
  comparing captures.
- Use an empty authenticated workspace for finance screenshots and do not capture
  credentials, customer records, or other private data.
- When no session is available, review protected routes through their sign-in
  behavior.

Presentation screenshots are kept in [docs/screenshots](screenshots/). Changes
to copy, authentication, data states, or navigation should be reviewed for
both visual correctness and accessibility.
